# 结构适配规则

在准备原文、定位结论或决定第二次阅读边界时使用本文件。

## 结论判断

| 论文情况 | 第一次阅读 Part 1 的处理 |
|---|---|
| 有独立 Conclusion / Conclusions | 正常精读，不增加确认问题 |
| 只有 Discussion / Summary / Closing Remarks 等等效章节 | 解释结构及候选章节，询问是否本次精读，等待选择 |
| 结论与实验、讨论或展望合并在同一节 | 说明合并位置，询问是否读该节或其中总结段，等待选择 |
| 无独立结论但末尾有明确总结段 | 指出实际段落位置，询问是否作为替代内容精读 |
| 没有可信的总结候选 | 说明未找到，询问是否跳过结论部分 |
| 只有摘要或正文缺页 | 说明缺失，精读可访问部分，等待补充材料或明确的跳过要求 |

用户选择阅读替代内容时完成它，再给比喻并结束 Part 1；用户选择跳过时说明选择，完成剩余 Part 1。此类回答处理当前阶段的未决问题，不自动推进下一阶段。

## 第二次阅读的边界

| 论文结构 | 范围 |
|---|---|
| 常规实证论文 | 引言开始，到独立实验、评测或实证结果章之前；在此之前的独立训练/实现章节照常速读 |
| 没有独立实验章但正文有实证评测 | 从引言读到结论/等效总结之前；穿插评测按原文章节一起速读，不以首次评测段落截断 |
| 结果章名为 Results / Evaluation | 检查其功能；实证评测章作为实验边界 |
| 理论论文且无实验 | 引言开始，到结论/等效总结之前；保留主要假设、定理和证明思路 |
| 综述且无实验 | 引言开始，沿原文主题分类顺序读到结论之前 |
| 系统论文 | 从引言到系统评测之前；架构、设计和实现按真实顺序阅读 |
| 无实验且无结论/等效章节 | 说明结构，读到正文结束；排除参考文献、致谢及常规附录 |
| 实验与方法持续交织，没有独立评测章 | 按无独立实验章规则读到结论之前；仅在结论边界也无法确定或用户要求调整范围时询问具体安排 |
| 没有名为 Introduction 的章节 | 使用承担研究背景和问题陈述功能的开篇；保留实际标题 |

- 根据章节实际职责判断，不强造标准的五章结构。
- 第二次阅读的正常边界不决定其他阶段的覆盖：Part 2 仍覆盖全部已提供图表，通篇总结仍使用整篇证据。
- 附录中的证明或方法是理解正文所必需时，可以简短引用；用户要求读附录时按其范围执行。
- 论文没有图表时 Part 2 如实说明并结束；不为了满足模板生成图表。
- 论文版本、材料访问范围、用户指定顺序优先于惯常结构。

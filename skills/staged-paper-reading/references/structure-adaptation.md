# 结构适配规则

在准备原文、定位结论、划分正文精读与剩余阅读范围时使用。不输出原文页码、页数或范围。

## 结论判断

| 论文情况 | 第一次阅读的处理 |
|---|---|
| 有独立 Conclusion / Conclusions | 正常精读，不增加确认问题 |
| 只有 Discussion / Summary / Closing Remarks 等等效章节 | 解释结构及候选章节，询问是否精读，等待选择 |
| 结论与实验、讨论或展望合并在同一节 | 说明合并位置，询问读该节或总结段，等待选择 |
| 无独立结论但末尾有明确总结段 | 指出所在章节或段落，询问是否作为替代精读 |
| 没有可信总结候选 | 说明未找到，询问是否跳过 |
| 只有摘要或正文缺失 | 说明缺失，精读可访问部分，等待补充或明确跳过 |

替代或跳过选择没有一分钟默认。选择后补完第一次阅读，按需给比喻，再提出两个正文详细阅读选择；不自动进入下一阶段，不重做已完成内容。

## 第二次阅读：全部正文非实验部分精读

| 论文结构 | 精读范围及剩余阅读 |
|---|---|
| 常规实证论文 | 按真实顺序精读引言至独立实验、评测或实证结果章之前；此前训练/实现章节保留。实验后的独立非实验讨论、分析、限制等也精读 |
| 结果章名为 Results / Evaluation | 根据实际功能判断；实证评测内容留给剩余速读，理论结果仍精读 |
| 无独立实验章但方法中有评测 | 精读至结论/等效总结之前，穿插评测按完整章节一起阅读，不在首次评测段落截断 |
| 实验与方法持续交织 | 可分清的非实验小节精读，独立评测小节可留给剩余阅读；无法分开时保留完整章节精读，说明混合结构 |
| 理论论文无实验 | 精读引言至结论之前，覆盖假设、定理、主要证明链；附录证明留给可选剩余阅读或指定解释 |
| 综述无实验 | 沿真实主题分类顺序精读至结论之前 |
| 系统论文 | 精读架构、设计、实现及其他正文非评测内容，独立系统评测留给剩余阅读 |
| 无实验且无结论/等效章节 | 精读到正文结束；排除参考文献、致谢与附录，不强造边界 |
| 没有 Introduction 标题 | 使用承担研究背景与问题陈述功能的开篇，按实际标题组织 |
| 实验后仍有非实验章节 | 按原文顺序精读这些章节，不能因为已出现实验章就遗漏 |
| 结论已经在第一次阅读精读 | 核对并引用已有解释，无须重复；有新增上下文时补充 |

- 以章节实际功能判断，不强造标准五章结构。正常的“实验章之前”边界不能缩减“全部正文非实验部分”的要求。
- 用户选择图表或公式详解时，对应任务覆盖全部正文，含实验章，排除附录及独立补充材料；章节精读范围与这两个任务范围分开记录。
- 已提供的附录与独立补充材料属于可选剩余阅读范围，不计入两个默认是阈值。必要的附录条件可为解释正文简短引用，不意味着自动详读附录。
- 第一阶段选定的结论替代可能已覆盖部分讨论或实验，第二次阅读核对后引用，补足未读非实验内容；不因替代选择漏掉任务。
- 论文没有图表或公式时如实说明，不为满足模板生成。
- 论文版本、材料访问范围和用户明确调整优先；正常结构适配不必逐项请求确认，边界确实无法确定时再询问。
- 剩余阅读选择否时仍须为总结核对完整可访问证据，不能声称已向用户讲过被跳过部分。
